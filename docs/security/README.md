# Security Documentation For Second Shelf

Каталог `docs/security` содержит базовый комплект документов по ИБ для backend-системы `Second Shelf`.
Документы описывают текущую прикладную реализацию, границы ответственности сервисов и инфраструктурные меры,
которые должны быть обеспечены в эксплуатационной среде.

Набор документов подготовлен для системы, которую предварительно относят к классу `3-ИН` при размещении в Республике Беларусь.
Окончательная аттестация и состав компенсирующих мер зависят от конкретной среды развертывания, сетевой сегментации,
используемых средств защиты и эксплуатационных процедур.
